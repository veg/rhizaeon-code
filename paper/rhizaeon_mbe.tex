\abstract{Homologous recombination and horizontal gene transfer assemble mosaic chromosomes from divergent evolutionary lineages. Reticulate evolution shatters bifurcating trees. Existing detection methods remain trapped between computationally prohibitive phylogenetic changepoint algorithms that scale exponentially with breakpoint count and isolated triplet heuristics that trigger high false positive rates under mutational rate variation. We introduce \RhizAeon, an open-source framework that models reticulation as continuous trajectory mechanics in empirical metric spaces without evaluating trees or enumerating triplets. By coupling continuous phylogenetic cross-attention over landmark lineages with an unpolarized ancestral root token that absorbs autapomorphic noise, \RhizAeon deconvolves reticulation through physical force field dynamics in linear time. Across extensive coalescent benchmarks, operational stress tests, and large-scale parameter sweeps, \RhizAeon maintains strict false positive control on non-recombinant nulls while sustaining throughput exceeding 30 genomes per second. Empirical applications across wildlife Sarbecovirus spike chimeras, bacterial chromosome mosaicism in \textit{Streptococcus pneumoniae}, and primate \textit{HLA} Class I immunogenomics resolve deep reticulations and fine-scale micro-conversions in fractions of a second. The platform executes client-side surveillance within standard web browsers without server data transfer.}
