\section{Materials and Methods}
\label{sec:methods}

\subsection{Metric Space Embedding and Gower Trajectory Projection}
\label{subsec:methods_embedding_gower}
Let $\mathcal{S} = \{s_1, \dots, s_M\}$ denote a multiple sequence alignment of $M$ contemporary nucleotide sequences of length $L$ over alphabet $\Sigma = \{\text{A}, \text{C}, \text{G}, \text{T}\} \cup \{-\}$.
Pairwise evolutionary distances $D_{i,j} = d(s_i, s_j)$ are computed under the Tamura-Nei (TN93) continuous-time Markov substitution model \citep{tamura1993estimation} or normalized Hamming distance with pairwise gap deletion.
For large cohorts ($M > 64$), the algorithm avoids $O(M^2 L)$ all-to-all comparisons by selecting $N \ll M$ reference landmark genomes via sequential Farthest-Point Sampling \citep{gonzalez1985clustering} in strictly $O(N M L)$ operations.
Initial seed $s_{(1)}$ maximizes non-gap coverage, and each subsequent landmark $s_{(k)}$ maximizes the running minimum distance to previously selected landmarks:
\begin{equation}
s_{(k)} = \arg\max_{i \notin \{s_{(1)},\dots,s_{(k-1)}\}} \min_{1 \le j < k} d(s_i, s_{(j)}).
\label{eq:methods_fps}
\end{equation}
Farthest points span the divergence of the cohort.
For $M \le 64$, all sequences serve as reference channels ($N = M$).
When $M > 64$, Two-Pass Clonal Backbone Re-Anchoring purges candidate recombinants identified in an initial screening pass from the landmark pool so that reference coordinates anchor strictly upon unadmixed parental lineages.

From the reference distance matrix $\mathbf{D} \in \mathbb{R}^{N \times N}$, we form the element-wise squared matrix $[\mathbf{D}^{(2)}]_{i,j} = D_{i,j}^2$.
Applying geometric centering $\mathbf{H} = \mathbf{I}_N - \frac{1}{N} \mathbf{1}_N \mathbf{1}_N^T$ yields the doubly centered Gram matrix $\mathbf{B} = -\frac{1}{2} \mathbf{H} \mathbf{D}^{(2)} \mathbf{H}$ \citep{gower1966some}.
Spectral decomposition produces orthonormal eigenvectors $\mathbf{V} \in \mathbb{R}^{N \times N}$ and descending eigenvalues $\mathbf{\Lambda} = \operatorname{diag}(\lambda_1, \dots, \lambda_N)$, from which we retain the leading $d \le \min(4, N-1)$ dimensions with positive eigenvalues ($\mathbf{\Lambda}_d, \mathbf{V}_d$).
Static landmark coordinates evaluate as $\mathbf{x}_i = \mathbf{\Lambda}_d^{1/2} (\mathbf{V}_d)_{i, :}^T$, and macroscopic tree splits project onto the dominant eigenvectors \citep{buneman1974note}.

To track evolutionary affinities continuously without independent sliding-window MDS rotations, local distance vectors project into canonical coordinates via analytical Gower out-of-sample interpolation \citep{gower1968adding}.
Across an aligned window of width $W$ centered at site $u$ (default $W = 300$~nt, stride $S = 10$~nt), local distances from query sequence $i$ to reference landmarks form vector $\mathbf{d}_i(u) \in \mathbb{R}^N$.
Gower interpolation solves $\min_{\mathbf{z} \in \mathbb{R}^d} \sum_{j=1}^N (\|\mathbf{z} - \mathbf{x}_j\|^2 - d_i(j; u)^2)^2$ and yields the exact closed-form coordinate:
\begin{equation}
\mathbf{z}_i(u) = \frac{1}{2} \mathbf{\Lambda}_d^{-1/2} \mathbf{V}_d^T \left( \bar{\mathbf{d}}^2 - \mathbf{d}_i^2(u) \right) \in \mathbb{R}^d,
\label{eq:methods_gower}
\end{equation}
where $\bar{\mathbf{d}}^2 = \frac{1}{N} \mathbf{D}^{(2)} \mathbf{1}_N$.
Evaluating \eqref{eq:methods_gower} across chromosome coordinates builds the trajectory tensor $\mathbf{Z} \in \mathbb{R}^{M \times U \times d}$ while preserving rigid metric geometry without Procrustes alignments.

\subsection{Continuous Phylogenetic Cross-Attention and the Unpolarized Root Sink}
\label{subsec:methods_attention_root}
To weight cross-attention by evolutionary divergence, \RhizAeon generalizes Rotary Position Embeddings (RoPE, \citet{su2024roformer}) from linear sequence positions to continuous metric spaces.
From metric coordinates $\mathbf{x}_i \in \mathbb{R}^d$, we compute rotary phase angles $\bm{\theta}_i \in \mathbb{R}^{d_{\text{head}}/2}$ via frequency projection $\theta_{i, m} = \sum_{c=1}^d x_{i, c} \Theta_{m, c}$, weighted by dimension-wise spectral variance.
Query and key vectors $\mathbf{q}_i(u), \mathbf{k}_i(u) \in \mathbb{R}^{d_{\text{head}}}$ undergo block-diagonal Givens rotations $\mathbf{R}(\bm{\theta}_i)$.
Rotated inner products satisfy $\langle \mathbf{R}(\bm{\theta}_i) \mathbf{q}_i(u), \, \mathbf{R}(\bm{\theta}_j) \mathbf{k}_j(u) \rangle = \mathbf{q}_i(u)^T \mathbf{R}(\bm{\theta}_j - \bm{\theta}_i) \mathbf{k}_j(u)$ and decay monotonically as metric separation grows.
Phylogenetic divergence modulates cross-attention weights through this continuous geometric decay.

To calibrate geometric affinities against baseline neutral substitution, we add a continuous-time Markov substitution prior to the attention logits.
Pairwise homologous identity probability under neutral substitution rate $\lambda_h$ is $P_{i,j} = \epsilon_0 + (1 - \epsilon_0) \exp(-\lambda_h D_{i,j})$ with equilibrium nucleotide frequency $\epsilon_0 = 0.25$, and the logarithmic prior bias is $\text{PhyloBias}_{i,j} = \ln [\max(10^{-5}, P_{i,j})]$.
Composite unnormalized attention logits evaluate as:
\begin{equation}
S_u(i, j) = \frac{(\mathbf{R}(\bm{\theta}_i) \mathbf{q}_i(u))^T (\mathbf{R}(\bm{\theta}_j) \mathbf{k}_j(u))}{\sqrt{d_{\text{head}}}} + \text{PhyloBias}_{i, j}.
\label{eq:methods_logits}
\end{equation}

Lineage-specific rate variation challenges standard attention mechanisms because autapomorphic bursts lack contemporary donors.
When private substitutions surge without homologous counterparts in other leaves, standard leaf-only softmax forces mutations to affiliate with whichever contemporary taxon exhibits the smallest random mismatch and triggers false positive recombination calls.
Reserving index zero for an unpolarized ancestral root token $\mathbf{x}_{\text{root}} = \mathbf{0} \in \mathbb{R}^d$ eliminates this vulnerability.
The attention operator spans $N+1$ nodes and normalizes softmax across the ancestral root and all contemporary leaves:
\begin{equation}
A_u(i \to j) = \frac{\exp(S_u(i, j))}{\sum_{k=0}^N \exp(S_u(i, k))}, \quad \text{where} \quad A_u(i \to 0) + \sum_{j=1}^N A_u(i \to j) = 1.0.
\label{eq:methods_root_softmax}
\end{equation}
At sites bearing private autapomorphic mutations, query-key matching against contemporary leaves is strongly depressed ($S_u(i, j) \ll 0$), whereas the unmutated root token maintains baseline neutral affinity.
Consequently, private mutational flux routes harmlessly into node zero ($\lim A_u(i \to 0) = 1.0$).
Sinks absorb unshared noise.
The unpolarized root sink protects trajectory tracking against episodic rate acceleration, APOBEC hypermutation, and biological heterotachy.

\subsection{Statistical Changepoint Inference and Multi-Scale Deconvolution}
\label{subsec:methods_changepoints}
Because instantaneous attention weights fluctuate stochastically at individual polymorphic sites, \RhizAeon integrates attention across chromosome coordinates into cumulative affinity curves $C_{i, m}(u) = \sum_{v=1}^u \sum_{j \in \mathcal{B}_m} A_v(i \to j)$ for each phylogenetic clade $\mathcal{B}_m$.
The home clade maximizes total chromosome affinity: $m_{\text{home}}(i) = \arg\max_m C_{i, m}(L)$.
For any candidate donor clade $m \neq m_{\text{home}}$, the differential attention curve is:
\begin{equation}
Y_{i, m}(u) = C_{i, m}(u) - C_{i, m_{\text{home}}}(u).
\label{eq:methods_diff_trajectory}
\end{equation}
Under clonal evolution, home attention dominates throughout the alignment and the differential trajectory drifts downward with negative slope.
Recombination reverses the trajectory derivative within the converted donor tract and drives an upward excursion ($dY/du > 0$).

To test the clonal null hypothesis, we construct the centered Brownian bridge $B(u) = Y(u) - \frac{u}{L} Y(L)$ by subtracting linear chromosome drift.
By Donsker's functional central limit theorem \citep{donsker1951invariance}, the standardized process $W_L^0(t) = B(\lfloor t L \rfloor) / (\sigma \sqrt{L})$ converges weakly to a standard Brownian bridge whose trajectory supremum follows the two-sided Kolmogorov distribution \citep{kolmogorov1933sulla}.
To control family-wise error rates across the hierarchical pipeline without incurring an unconstrained $\mathcal{O}(N^3)$ hypothesis penalty, the boundary-crossing quantile $K_{\text{crit}}$ is calibrated at each operational stage:
\begin{equation}
K_{\text{crit}} = \sqrt{-\frac{1}{2} \ln \left( \frac{\alpha}{M} \right)},
\label{eq:methods_k_crit}
\end{equation}
derived from the asymptotic two-sided Kolmogorov extreme-value distribution \citep{kolmogorov1933sulla,donsker1951invariance}.
In the primary whole-chromosome screening pass (\texttt{screener.rs}), $M = 2N$ controls for positive and negative excursions across all $N$ evaluated sequences.
In candidate donor channel attribution (\texttt{attribution.rs}), $M = 2(K + 1)$ corrects for comparisons across the $K$ landmark reference channels and the root sink.
In post-polishing changepoint certification (\texttt{polishing.rs}), $M = 4N$ bounds the two-sided trajectory verification across polished segment boundaries.
Trajectories satisfying $\sup |B(u)| / (\sigma \sqrt{L}) \ge K_{\text{crit}}$ reject the unreticulated clonal null.

For short conversion tracts ($< 200$~nt), global Brownian bridge tests can suffer signal dilution across megabase chromosomes.
Convolving trajectory flux $\Delta Y(u)$ with a bank of zero-mean bipolar dyadic matched filters $h_\tau(s)$ across scales $\tau \in \{15, 25, 50, 100, 200, 500\}$~nt isolates step transitions in scale space.
Running drawdown $\text{DD}(u) = \max_{v \le u} Y(v) - Y(u)$ localizes coordinates where trajectory momentum collapses and marks tract exit boundaries.
To separate single crossovers from intercalary cassette swaps, we evaluate the outer-to-inner energy density ratio $\mathcal{E}_{\text{ratio}}$ across flanking versus internal segments.
Cassettes return cleanly to baseline on both flanks ($\mathcal{E}_{\text{ratio}} < 0.15$), whereas single crossovers maintain elevated offset energy across the chromosome ($\mathcal{E}_{\text{ratio}} \ge 0.50$).

Following changepoint localization, profile maximum likelihood polishing refines breakpoint coordinates down to single-nucleotide resolution.
Scanning coordinates $c \in [u_{\text{init}} - \delta, u_{\text{init}} + \delta]$ maximizes partitioned log-likelihood $\ln \mathcal{L}(c) = \sum_{u=1}^c \ln P(s_{\text{rec}}(u) \mid s_{\text{left}}(u)) + \sum_{u=c+1}^L \ln P(s_{\text{rec}}(u) \mid s_{\text{right}}(u))$.
Across invariant sites, the likelihood forms a flat plateau, and the polisher reports the exact 95\% confidence interval $[c_{\text{left}}, c_{\text{right}}] = \{c : \ln \mathcal{L}(c) \ge \max \ln \mathcal{L} - 1.92\}$ bounded by physical informative mutations.
Continuous gap bridging iteratively coalesces adjacent donor fragments separated by non-informative intervals ($\le 150$~bp) whenever net flux across the merged span remains positive.

\subsection{Attention Force Field Deconvolution and Multi-Channel Trajectory Resolution}
\label{subsec:methods_force_field}
To resolve multi-way mosaics without combinatorial heuristics, cross-attention dynamics is formalized as an empirical force field.
At each position $u$, the directed attention weight $A_u(i \to j)$ defines the instantaneous attraction pulling query sequence $i$ toward reference taxon $j$.
Subtracting the sequence's genome-wide mean baseline affinity $\bar{A}(i \to j) = \frac{1}{L}\sum_{v=1}^L A_v(i \to j)$ produces the zero-drift attention force field:
\begin{equation}
F_u(i \to j) = A_u(i \to j) - \bar{A}(i \to j), \quad \text{where} \quad \sum_{u=1}^L F_u(i \to j) = 0.
\label{eq:methods_force_field}
\end{equation}
Integrating this directed force across chromosome coordinates yields the cumulative momentum trajectory $C_{i, m}(u) = \sum_{v=1}^u \sum_{j \in \mathcal{B}_m} F_v(i \to j)$ for each reference clade $\mathcal{B}_m$.
Under clonal evolution, instantaneous forces fluctuate around zero as balanced thermal noise, and the cumulative momentum behaves as a centered random walk bounded within Kolmogorov confidence intervals.
When a recombination event incorporates an introgressed segment, persistent directional affinity toward the donor exerts a continuous force that imparts positive momentum to $C_{i, \text{donor}}(u)$ while depressing home momentum.

To deconvolve complex genomes bearing multiple mosaic tracts or divergent parental donors, differential momentum curves are evaluated across all candidate donor channels $k \in \{1, \dots, K\}$:
\begin{equation}
Y_{i, k}(u) = C_{i, k}(u) - C_{i, \text{home}}(u).
\label{eq:methods_channel_momentum}
\end{equation}
Dyadic wavelet matched filters and running drawdown $\text{DD}_k(u) = \max_{v \le u} Y_{i, k}(v) - Y_{i, k}(u)$ extract crossover and cassette changepoints whose excursions exceed $K_{\text{crit}}$.
Evaluating channel contrast resolves overlapping candidate alerts without threshold tuning: for any candidate tract $[u_1, u_2]$, the authentic donor channel maximizes the mean in-tract attention flux while maintaining negative or baseline flux in flanking regions.
Merging concordant intervals deduplicates candidate events across channels and yields a unified non-redundant inventory of reticulations across the chromosome.

\subsection{Reticulation Graph Adjudication and Ancestral Event Grouping}
\label{subsec:methods_adjudication}
In reciprocal triplet scans, recombinant isolate $C$ inheriting sequence from donor $D$ into home $H$ frequently triggers reciprocal false alarms ($D$ recombinant between $C$ and $H$).
Reciprocal scanning artifacts create mutual two-cycles in candidate reticulation graphs ($C \leftrightarrow D$).
Cycle adjudication resolves orientation by evaluating transition contrast $\Delta_{\text{trans}} = \Delta d_{\text{home}} + \Delta d_{\text{donor}}$, where $\Delta d_{\text{home}} = \max(0, d(C, H \mid \text{tract}) - d(C, H \mid \text{flank}))$.
Authentic recombinant children leave their home background within the tract ($\Delta d_{\text{home}} \gg 0$), whereas stationary clonal parents remain within their home background across the alignment ($\Delta d_{\text{home}} \approx 0$).
Comparing transition contrast purges reciprocal parent false alarms.

In expanding epidemic outbreaks, multiple descendant isolates inherit identical mosaic tracts from a common recombinant ancestor.
Reporting each isolate as an independent recombination event inflates event counts and misrepresents evolutionary history.
Graph adjudication clusters candidate events into shared ancestral recombination events using a bidirectional interval overlap criterion.
Events sharing concordant resolved Home and Donor lineages in either direct ($\text{Home}_1 = \text{Home}_2, \text{Donor}_1 = \text{Donor}_2$) or inverted ($\text{Home}_1 = \text{Donor}_2, \text{Donor}_1 = \text{Home}_2$) polarity whose breakpoint intervals overlap by $\ge 50\%$ of the shorter tract (or share a complementary crossover junction within $100$~nt under inverted polarity):
\begin{equation}
\frac{\min(u_2^{(1)}, u_2^{(2)}) - \max(u_1^{(1)}, u_1^{(2)}) + 1}{\min(u_2^{(1)} - u_1^{(1)} + 1, \, u_2^{(2)} - u_1^{(2)} + 1)} \ge 0.50,
\label{eq:methods_ancestral_overlap}
\end{equation}
collapse into a single ancestral event that aggregates the complete roster of co-recombinant isolates ($\mathcal{I} = \{s_1, \dots, s_k\}$).
Consensus breakpoints span the outer envelope $[\min_k u_{1, k}, \max_k u_{2, k}]$ while retaining maximal statistical significance across member isolates.
Each unique event receives a persistent sequential identifier ($1, 2, \dots$) to report both unique evolutionary events and total recombinant isolates across the alignment inventory.

\subsection{Coalescent Simulation Suites and Bipartite Hungarian Evaluation}
\label{subsec:methods_benchmarks}
Synthetic alignments were generated under Hudson's neutral coalescent model with recombination \citep{hudson1983properties,posada2001evaluation} across 3,200 alignments spanning 16 parameter regimes.
Simulations crossed sequence divergence $\theta \in \{10, 50, 100, 200\}$, recombination rate $\rho \in \{0, 1, 4, 16, 64\}$, and rate heterogeneity $\alpha \in \{2.0, 0.5, 0.05\}$ across 1,200 null and 2,000 recombinant alignments (100 replicates each, Supplementary Table~\ref{tab:supp_posada_summary}).
To evaluate operational challenges and compare against both raw 3SEQ triplet outputs and best-practice post-processed 3SEQ event inventories (\texttt{3SEQ (Consolidated)}, which selects the minimum-$p$ triplet per query sequence, purges reciprocal parent-child inversions via directional transition contrast, and merges overlapping co-recombinant intervals by $\ge 50\%$ overlap), four specialized scenario suites were simulated under HKY85 substitution dynamics ($\kappa = 2.5, \pi = [0.3, 0.2, 0.2, 0.3]$) across 2,280 alignments:
\begin{enumerate}
\item \emph{Epidemic Clonal Expansion}: Recombinant ancestors sprouting $K \in \{2, 5, 8, 10, 15\}$ descendants with transmission drift ($\delta = 0.002$) alongside 40 parental background isolates ($N = 42\text{--}55$, $L = 5,000$~nt, 300 alignments).
\item \emph{Multi-Way Mosaic Clusters}: Dual-cassette transfers, nested Russian doll introgressions, and triple crossover cascades with $K \in \{1, 5, 10\}$ descendants across $d \in \{0.02, 0.05, 0.10\}$ ($N = 46\text{--}55$, $L = 6,000$~nt, 540 alignments).
\item \emph{Ghost Donor Introgression}: Pure unsampled donor, surrogate sister clade, and deep reservoir donor regimes across cluster sizes $K \in \{2, 5, 10\}$ ($N = 32\text{--}40$, $L = 5,000$~nt, 540 alignments).
\item \emph{Micro-Conversion Resolution}: Conversion tracts spanning $L_{\text{tract}} \in \{50, 100, 200, 400, 800\}$~nt across three divergence tiers ($N = 32\text{--}40$, $L = 5,000$~nt, 900 alignments).
\end{enumerate}
In addition, a grand continuous parameter sweep of 1,000,000 whole genomes evaluated continuous distributions across chromosome length $L \in [300, 30{,}000]$~nt, cohort size $N \in [4, 250]$~taxa, and divergence $d \in [0.005, 0.35]$~subs/site.
The parameter sweep crossed Gamma rate shape $\alpha \in [0.2, 5.0]$ alongside strict molecular clock controls ($\alpha \ge 50$), single and multi-event mosaic topologies ($K_{\mathrm{true}} \in \{0, 1, 2, 3, 4\}$), and multi-donor introgressions ($P_1 \leftarrow P_2 + P_3$, Table~\ref{tab:grand_sweep_1m_envelope}).

Ground truth was evaluated via maximum-weight bijective bipartite matching using the Hungarian algorithm \citep{kuhn1955hungarian}.
For true event $E = (C, H, D, \mathcal{I})$ and inferred event $\hat{E} = (\hat{C}, \hat{H}, \hat{D}, \hat{\mathcal{I}})$, event affinity combines genealogical triad affinity and informative SNP Jaccard similarity:
\begin{equation}
s(E, \hat{E}) = \left[ w(C, \hat{C}) \times \frac{w(H, \hat{H}) + w(D, \hat{D})}{2} \right] \times \frac{|\mathcal{S}_{\text{true}} \cap \mathcal{S}_{\text{inferred}}|}{|\mathcal{S}_{\text{true}} \cup \mathcal{S}_{\text{inferred}}|},
\label{eq:methods_event_affinity}
\end{equation}
where $w(X, Y) = \exp(-d_{\text{tree}}(X, Y) / \sigma_{\text{clade}})$.
Across the optimal matching $\mathcal{M}$, reticulation precision and recall are $\text{PPV}_{\mathcal{R}} = \frac{1}{\hat{K}} \sum_{\mathcal{M}} s(E_i, \hat{E}_j)$ and $\text{TPR}_{\mathcal{R}} = \frac{1}{K} \sum_{\mathcal{M}} s(E_i, \hat{E}_j)$.
The composite Reticulation Fidelity Index is their harmonic mean $\mathcal{R}_{F_1} = 2 \cdot \text{PPV}_{\mathcal{R}} \cdot \text{TPR}_{\mathcal{R}} / (\text{PPV}_{\mathcal{R}} + \text{TPR}_{\mathcal{R}})$.
Every unmatched true event penalizes recall, whereas every ungrounded prediction penalizes precision.

\subsection{Empirical Genomic Datasets, Software Availability, and Data Distribution}
\label{subsec:methods_empirical}
Empirical evaluations analyzed three natural evolutionary cohorts:
\begin{enumerate}
\item \emph{Sarbecovirus Genomes}: We analyzed the primary 78-taxon sarbecovirus alignment of \citet{lytras2022exploring} (30,956~bp multiple sequence alignment, 13,550 total polymorphic columns, 13,160 gap-filtered sites), which \citet{lytras2022exploring} screened via RDP5 across all 78 genomes and via GARD on a 22-virus subset to define 21 consensus breakpoints. We also analyzed an expanded 83-taxon alignment (30,965~bp MSA, 13,260 gap-filtered sites) adding the five Laotian \textit{Rhinolophus} bat sarbecoviruses (BANAL-20-52, BANAL-20-103, BANAL-20-116, BANAL-20-236, and BANAL-20-247) from \citet{temmam2022bat}, anchored to Wuhan-Hu-1 reference NC\_045512.2 (Supplementary Table~\ref{tab:supp_sarbeco_coord_conversion}).

\item \emph{Bacterial Chromosomes}: 11 clinical isolates of multidrug-resistant \textit{Streptococcus pneumoniae} PMEN1 (2,221,315~nt, \citealt{croucher2011rapid}) spanning global penicillin-resistant outbreaks.
\item \emph{Primate Immunogenomics}: 379 classical primate MHC Class~I alleles (\textit{HLA-A}, \textit{HLA-B}, \textit{HLA-C}, and non-human hominoid orthologs, 1,128~nt, \citealt{maccari2017ipd}).
\end{enumerate}

\RhizAeon is implemented in native Rust with Rayon multicore parallelization and PyO3 Python bindings.
The algorithmic core compiles to WebAssembly (WASM) so surveillance pipelines execute client-side within standard web browsers without remote server transmission.
Interactive dashboards render synchronized signal inspectors, 2D metric subspace projections, and midpoint-rooted phylogenetic trees within browser canvas.
All raw multiple sequence FASTA alignments, empirical cohort datasets, and simulation benchmark suites are distributed within the project repository under \texttt{empirical\_datasets/} and \texttt{benchmarks/}.
Source code, documentation, and benchmark workflows are freely available under the MIT license at \url{https://github.com/veg/rhizaeon-code}.

\subsection{Data Governance and Biosafety Compliance}
\label{subsec:methods_biosafety}
All genomic analyses conducted in this study represent 100\% retrospective, computational \textit{in silico} modeling of publicly available, previously published nucleotide sequence accessions retrieved from GenBank, GISAID, and the IPD-IMGT/HLA database.
Zero handling, isolation, propagation, transport, or laboratory manipulation of biological specimens, viable pathogens, or clinical tissue samples occurred at any stage of the study.
All synthetic sequence benchmarks were generated computationally using coalescent tree simulators and continuous-time Markov substitution models.
