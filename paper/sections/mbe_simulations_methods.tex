\subsection{Simulation Protocols and Benchmark Frameworks}
\label{subsec:methods_simulations}

\paragraph{Continuous-Time Markov Substitution Modeling.}
All simulated alignments evolved under continuous-time Markov substitution dynamics. Nucleotide evolution followed the HKY85 model with transition/transversion ratio $\kappa = 2.5$ and equilibrium base frequencies $\bm{\pi} = [0.30, 0.20, 0.20, 0.30]$ (or $\kappa = 2.0$, $\bm{\pi} = [0.40, 0.20, 0.30, 0.10]$ for Posada \& Crandall controls). Finite-time transition probability matrices $\mathbf{P}(t)$ across branches of length $t$ were evaluated analytically via matrix exponentiation:
\begin{equation}
\mathbf{P}(t) = \exp(\mathbf{Q} \cdot t),
\end{equation}
where $\mathbf{Q}$ is the normalized generator rate matrix. Continuous site-rate heterogeneity was modeled by drawing relative site mutation rates $r_i \sim \text{Gamma}(\alpha, \alpha)$ using Marsaglia and Tsang's exact transformation rejection algorithm. For strict molecular clock controls, $\alpha$ was clamped to $100.0$; for biological heterotachy, $\alpha$ varied continuously across $[0.05, 5.0]$.

\paragraph{The 1,000,000-Genome Grand Sweep Generation Protocol.}
The one-million whole-genome sweep was executed using the compiled native Rust benchmark harness (\texttt{grand\_sweep.rs}) under Rayon multi-threaded parallelism across 512 distributed CPU cores on cluster infrastructure (50 Slurm array tasks $\times$ 20,000 trials). For each trial:
\begin{enumerate}
    \item \textit{Dimensional Parameter Sampling}: Genome length was drawn from $L \sim \text{LogUniform}(1{,}000, 30{,}000)$~nt (median $5{,}450$~nt); cohort size from $N \in [4, 250]$~taxa across small (40\%), medium (40\%), and large (20\%) surveillance regimes; parental sequence divergence from $d_{\mathrm{parent}} \sim \text{LogUniform}(0.005, 0.250)$~subs/site; and Gamma shape $\alpha$ was sampled from $\text{LogUniform}(0.05, 5.0)$ with probability 0.75 and set to $1{,}000.0$ (clock-like) with probability 0.25.
    \item \textit{Reticulation Cardinality and Topologies}: Clonal nulls ($K_{\mathrm{true}} = 0$, $333{,}334$ trials) established false positive calibration. Recombinant trials ($N = 666{,}666$) spanned single crossovers and conversion cassettes ($K=1$, 55\%), dual events ($K=2$, 25\%), triple events ($K=3$, 12\%), and quadruple events ($K=4$, 8\%), including multi-donor mosaics ($P_1 \leftarrow P_2 + P_3$, $N = 179{,}233$).
    \item \textit{Recombinant Implantation}: For each event, terminal 5' crossovers, 3' crossovers, or intercalary conversion cassettes ($L_{\mathrm{tract}} \sim \text{LogUniform}(30, 0.65 \times \text{segment length})$) were implanted between ancestral nodes prior to terminal transmission drift ($d_{\mathrm{drift}} \sim \text{Uniform}(0.0005, 0.0035)$).
    \item \textit{Automated Scanning and Matching}: Each alignment was evaluated using the compiled engine, logging classification, wall-clock latency, and event precision/recall via bijective bipartite matching.
\end{enumerate}

\paragraph{Targeted Failure Mode Benchmarks and Scoring Standards.}
Targeted failure mode benchmarks were executed using Python harnesses incorporating \texttt{scipy.linalg.expm} and automated calls to the compiled \texttt{rhizaeon} binary and \texttt{3seq} (v1.7):
\begin{itemize}
    \item \textit{Breakpoint Spatial Accuracy}: Evaluated via Informative SNP Jaccard Index ($J_{\mathrm{SNP}}$) over the flanking informative polymorphisms $[u_{\mathrm{left}}, u_{\mathrm{right}}]$ bounding the physical exchange. Exact plateau containment ($E_{\mathrm{SNP}} = 0$) achieves $J = 1.00$.
    \item \textit{Cardinality and Lineage Attribution}: Inferred events were paired to ground truth via 1-to-1 bijective bipartite matching using the Hungarian algorithm (\texttt{scipy.optimize.linear\_sum\_assignment}) on spatial boundary distance. Spurious extra calls were penalized as false alarms (deflating precision $\text{PPV}$); missed events deflated recall.
    \item \textit{Parental Specificity}: The parental false positive rate ($\text{FPR}_{\mathrm{parent}}$) measured the proportion of un-introgressed background parental lineages falsely classified as recombinant children.
\end{itemize}
